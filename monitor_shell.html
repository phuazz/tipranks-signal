TipRanks Signal Monitor

Hosted code, local data. This page carries no vendor values — load this week's export from your own machine to populate it.
Drop the weekly export here tipranks_monitor_YYYY-MM-DD.html
Nothing is uploaded. The file is read in this browser and cached here (IndexedDB) so a reload does not need it again. This is a static page with no backend; the per-name data cannot leave this device through it.
Produce the export with python scripts/capture.py --latest --asof YYYY-MM-DD, or python scripts/export_html.py alone. It lands in data/exports/ and is copied to OneDrive\Main\tipranks-signal\, so any device signed in to OneDrive can load it. dashboard_data.json also works, without the price charts.
